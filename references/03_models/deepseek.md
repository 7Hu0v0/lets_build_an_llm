# DeepSeek

## TL;DR

DeepSeek 是近年开源大模型路线中非常重要的模型家族，适合观察 MoE、reasoning training、coding、long context、RL 和开源技术报告的结合。这个条目重点关注它如何用相对开放的方式展示模型工程选择。

## Definition

DeepSeek refers to DeepSeek's model family, including general language models, coding models, reasoning models, and open-weight or openly documented model releases.

## Pipeline Position

DeepSeek 适合放在 architecture、training infrastructure、pretraining、post-training、evaluation 和 open-source ecosystem 中观察。它的价值不只在模型本身，也在技术报告和开源实践提供的学习样本。

## Technical Mechanism

需要关注 MoE routing、activated parameters、training efficiency、reasoning-oriented post-training、code data、RL methods、distillation 和 deployment cost。分析时应优先参考官方 technical report、model card、论文和 GitHub release。

## Common Misunderstandings

- 只把 DeepSeek 当作性价比模型，而忽略其训练和工程路线。
- 把开源权重等同于完全透明，忽略数据和训练细节仍可能不完整。
- 只看 reasoning 表现，不看 infra、eval 和 deployment 约束。

## Recruiting Lens

能讲清 DeepSeek 的 MoE、RL、reasoning 和开源策略的候选人，通常对模型工程和开源生态都有较强理解。pre-talk 可以追问：DeepSeek 的哪些设计会影响训练成本、推理成本和团队分工？

## Simple Analogy

DeepSeek 像一份相对可拆解的 LLM 工程样本：不仅给你结果，也给你很多观察模型如何被造出来的线索。
