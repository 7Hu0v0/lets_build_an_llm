# Llama

## TL;DR

Llama 是 Meta 的 open-weight 模型家族，对全球开源 LLM 生态影响很大。这个条目关注 Llama 如何推动 fine-tuning、deployment、research reproduction、model distillation 和应用生态发展。

## Definition

Llama refers to Meta's open-weight foundation model family, covering general language, instruction-following, coding, multimodal, and smaller deployable variants.

## Pipeline Position

Llama 适合放在 open-weight ecosystem、pretraining、post-training、fine-tuning、inference deployment 和 research reproduction 中观察。它的影响力来自模型能力，也来自开放权重带来的生态扩散。

## Technical Mechanism

需要关注 Llama 的模型尺寸、训练数据披露、instruction tuning、license、deployment friendliness、quantization、community fine-tuning 和 downstream adaptation。理解 Llama 时要把模型本体和社区生态分开看。

## Common Misunderstandings

- 把 open-weight 误解为完全 open-source 或完全透明。
- 只看原始模型能力，不看社区 fine-tune 和部署生态。
- 忽略 license 对商业使用和企业采用的影响。

## Recruiting Lens

懂 Llama 的候选人往往能更好地讨论模型落地、私有化部署、fine-tuning、评测和开源生态选择。pre-talk 可追问：什么情况下你会选择 Llama，而不是闭源 API 或其他开源模型？

## Simple Analogy

Llama 像 LLM 世界的基础零件平台：很多团队不会从零造模型，而是在它上面改造、部署和验证想法。
