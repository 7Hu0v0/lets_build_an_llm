# Claude

## TL;DR

Claude 是 Anthropic 的主力模型家族，常被用来观察 safety、alignment、long context、writing quality、tool use 和 agentic workflows 的演进。这个条目关注 Claude 的技术路线如何连接 Constitutional AI、RLHF/RLAIF、extended thinking 与企业级使用场景。

## Definition

Claude refers to Anthropic's assistant model family, covering general chat, reasoning, coding, multimodal, long-context, and tool-use capabilities.

## Pipeline Position

Claude 主要值得放在 post-training、evaluation、safety、inference productization 和 agent workflow 中观察。它不是单纯的模型参数问题，而是模型行为、对齐策略、上下文处理和工具编排共同形成的系统。

## Technical Mechanism

需要关注 Claude 如何通过 alignment、preference optimization、safety policy、long-context engineering 和 tool-use interfaces 提升可控性与任务完成质量。对于闭源部分，需要以官方文档、model card、system card 和可复现实验为边界。

## Common Misunderstandings

- 把 Claude 的写作风格等同于全部技术能力。
- 只讨论 safety，而忽略 long context、coding、tool use 和 workflow integration。
- 用单次主观体验判断模型家族整体能力。

## Recruiting Lens

能讲清 Claude 与 GPT、Gemini、Llama 等模型在 alignment philosophy、product positioning 和 enterprise adoption 上差异的候选人，通常更适合做模型评测、产品策略、agent workflow 或技术招聘判断。

## Simple Analogy

Claude 像一个强调边界感和工作流可靠性的高级协作者：不只是会回答，还要尽量稳定、可控、适合长期任务。
