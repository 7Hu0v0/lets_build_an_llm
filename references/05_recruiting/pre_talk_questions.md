# Pre-talk Questions

## TL;DR

Pre-talk Questions 是把 LLM 技术理解转化为候选人沟通的问题库。好的问题不追求难倒候选人，而是帮助快速定位 TA 的真实经历、技术深度和团队匹配度。这个条目用于沉淀可复用的 AI recruiting 问法。

## Definition

Pre-talk Questions are structured questions used before formal interviews to understand a candidate's real work, ownership, technical depth, and role fit.

## Pipeline Position

Pre-talk Questions 应该按 pipeline stage 组织：compute、data、architecture、training infra、pretraining、post-training、evaluation、inference、agent、online feedback。每类问题都要服务于人才判断，而不是纯知识考试。

## Technical Mechanism

每组问题应包含 opening question、deep-dive question、follow-up question 和 red-flag question。问题设计要从事实入手：项目背景、个人职责、技术难点、指标、失败案例、协作对象和上线结果。

## Common Misunderstandings

- 把 pre-talk 做成技术面试。
- 问太抽象的问题，导致候选人只能泛泛回答。
- 只问模型名和框架名，不问真实 ownership。

## Recruiting Lens

强问题能让候选人自然暴露深度：做过的人会讲约束、指标、权衡和坑；没做过的人通常停留在概念和二手信息。pre-talk 的目标是提高正式面试匹配度，而不是替代面试。

## Simple Analogy

Pre-talk Questions 像探照灯：不是为了审判候选人，而是照出 TA 真正走过哪段路。
