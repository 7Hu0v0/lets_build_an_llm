# LM Wiki: Let's Build an LLM

这是一个面向非技术人员的 **大模型工业系统知识库**。

我希望用 Wiki 的方式，系统拆解一个 LLM 是如何被 build 出来的：从算力、数据、模型架构、训练基础设施，到预训练、后训练、评测、推理部署、Agent 和线上反馈。

这个项目不是论文综述，也不是模型新闻合集，而是一套尽量清晰、结构化、可检索、可复用的 Markdown Knowledge Base。它服务于三个目标：

1. 帮助非技术背景的人理解 LLM；
2. 帮助我沉淀 AI 技术认知；
3. 支持 AI Talent Mapping、候选人 pre-talk 和技术招聘判断。

核心原则很简单：

> 如无必要，勿增实体。

每个词条只解决一个问题，每个概念都要放回 LLM 工业链路中理解。  
最终，我希望这个 Wiki 不只是给人读，也能被 AI Agent 调用，帮助我持续学习、复盘和判断真实技术能力。
