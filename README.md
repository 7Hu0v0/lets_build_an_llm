# Let's Build an LLM

这是一个面向非技术人员的大模型学习笔记项目。

我希望从自己的视角出发，系统理解一个 LLM 是如何被 build 出来的：从算力、数据、模型架构，到预训练、后训练、评测、推理部署、Agent 和线上反馈。

这个项目不是论文综述，也不是模型新闻合集，而是一套尽量清晰、结构化、可复用的 Markdown Knowledge Base。它既帮助我学习大模型工业系统，也希望帮助更多非算法背景的人理解：模型能力背后到底发生了什么。

最终，我希望它能服务三个目标：  
1. 帮助非技术人员理解 LLM；  
2. 帮助自己沉淀 AI 技术认知；  
3. 支持 AI Talent Mapping、候选人 pre-talk 和技术招聘判断。

原则很简单：如无必要，勿增实体。
